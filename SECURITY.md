# Security policy

## Reporting a vulnerability

Use GitHub's [private vulnerability reporting](https://github.com/ArgyleConcepts/FSharp.Actor/security/advisories/new) for this repository. Do not open a public issue or pull request containing an undisclosed vulnerability.

Include the affected version or commit, a minimal reproduction, expected impact, and any suggested fix. Remove real credentials and personal data. Maintainers will use the private advisory to discuss investigation, remediation, and disclosure with you. Response times depend on maintainer availability.

## Supported versions

Security fixes target `main` and are released in the latest `1.x` package. No older version has a promised backport or long-term support commitment.
